# CRUX · 双板摇臂机关岩壁

一个确定性的 2D 攀岩机关关卡：两块装着岩点的板共用同一根摇臂，一侧下降时另一侧升高。玩家用脚踩住中央踏点后可有限次驱动摇臂；移动其他肢体时，踩点脚会继续压住机关。

## 玩法

```sh
npm ci
npm run dev
```

构建与类型检查：

```sh
npm run typecheck
npm run build
```

### 操作顺序

1. 选择左手 / 右手 / 左脚 / 右脚。
2. 点击岩壁岩点，查看触及范围、断开瞬间余量和落点余量。
3. 余量为负的动作仍可执行，用于触发坠落复盘；无效占用或手踩机关不会提交。
4. 让任意一只脚留在 `T` 上，点击“踩下机关”。
5. 左侧面板提供 11 步通关顺序，可“按此顺序引导我”，也可“自动演示”。
6. 底部内置：
   - **通关示例**：保留关键支撑并成功完攀；
   - **卡止样本**：左脚踩上右板承重凸轮点 `21` 后换向，摇臂在 `5.1°` 被该接触拦住；
   - **失衡样本**：换上两个低支撑斜面点后松开右脚，在断开瞬间以 `-0.7` 余量失衡。

## 机关与复盘模型

- 摇臂角范围为 `-11° … +11°`，左右板位移由同一个 `boardPose(level, angle)` 计算，严格反向。
- 岩点坐标分板内局部坐标和世界坐标；复盘到任意角度时，身体重心只从当时仍连接的接触点计算。
- 每次移动分别计算：
  - 断开所选肢体后、剩余接触的支撑余量；
  - 落到目标点后的支撑余量；
  - 当前摇臂角下的触及距离。
- 触发预演会沿角度扫描：
  - 支撑余量先变负：报告失衡角度；
  - 承重接触和凸轮阻力使驱动余量降到零：报告卡止角度、肢体和岩点；
  - 否则完整翻到对面限位角。
- 触发次数是有限资源；每次提交触发都会消耗一次，卡止也会留下次数和角度状态。
- 复盘的“停到第一次失衡 / 卡止”会跳到时间线中第一个严重事件。可在“关键瞬间 / 动作前 / 结果姿态”之间切换，并读取该时刻的摇臂角、两块板位移和接触配置。
